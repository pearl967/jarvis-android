# JARVIS — локальный голосовой помощник для Android

Нативный Android-клиент для локального OpenJarvis. Без Telegram и рут-прав; облачный ключ Yandex нужен только если вы хотите голос Yandex вместо системного TTS. Отвечает голосом, слушает wake-слово «Джарвис», показывает HUD и работает в непрерывном режиме.

## Быстрый старт на телефоне

1. Скачайте `apk/Jarvis.apk` со страницы GitHub Pages (ссылка `apk/Jarvis.apk` в `index.html`).
2. **Важно:** если на телефоне уже стоит старая версия JARVIS, удалите её — у новой сборки другой ключ подписи. После этого обновления будут ставиться поверх без удаления.
3. Разрешите установку из неизвестных источников для приложения, которым открыли APK.
4. Если установка заблокирована:
   - Play Market → Play Protect → шестерня → временно выключите «Сканировать приложения»;
   - либо Настройки → Безопасность → Установка неизвестных приложений → разрешите браузеру/файловому менеджеру.
5. Откройте JARVIS и разрешите доступ к микрофону.
6. В `НАСТРОЙКИ ЯДРА` укажите адрес сервера: `http://<IP-контейнера>:8001/v1/chat/completions`.
   Текущий IP можно посмотреть командой `ip -4 addr show wlan0` в контейнере.
7. Нажмите `ПРОВЕРКА СВЯЗИ`, затем скажите «Джарвис, …».

## Серверная часть

В контейнере Ubuntu/qroot:

```bash
ollama pull qwen3:0.6b
bash scripts/start-openjarvis.sh
```

Скрипт поднимает:

- `llama-server` с моделью `qwen3:0.6b` на `127.0.0.1:8081` (быстрый локальный вывод на 8 ядрах aarch64);
- OpenJarvis API на `127.0.0.1:8000` (CLI/GUI);
- мост для Android на `0.0.0.0:8001` (потоковый SSE-прокси);
- веб-GUI на `127.0.0.1:5173`.

### Почему так

Встроенный раннер Ollama в qroot не запускается (`fork/exec ... no such file or directory`), поэтому модель запускается напрямую через `llama-server`. OpenJarvis API остаётся на loopback, чтобы GUI не требовал API-ключ; телефон ходит через локальный мост.

## Возможности

- Wake-слова: `джарвис`, `jarvis`, `чарвис`, `чарви`.
- Непрерывное прослушивание с автоперезапуском.
- Потоковый вывод ответа в HUD (токены появляются по мере генерации).
- Синтез речи по предложениям: JARVIS начинает говорить, не дожидаясь конца ответа.
- «Перебивание»: если начать говорить во время ответа, синтез речи останавливается.
- Короткие таймауты тишины распознавателя (550 мс) — быстрый отклик.
- Ответы ограничены 1–2 предложениями, `max_tokens=96`.
- Индикация времени ответа.
- Режим ввода текста и настройка адреса ядра.
- **Голос:** выбор любого установленного движка TTS и голоса (включая Google/Yandex TTS), либо облачный Yandex SpeechKit v3 с вашим API-ключом.
- **Локальные команды без модели:** «который час», «какое число», «проверь батарею», «сколько будет 2+2», «стоп», «кто ты».
- **SMS:** «прочитай смс», «ответь <текст>», «отправь смс <номер> <текст>».
- **Звонки:** «ответь на звонок», «отбей звонок» (нужна роль приложения для звонков на modern Android).
- **Приложения:** «открой камеру» и другие по имени.
- **Уведомления:** «прочитай уведомления» (нужен доступ к уведомлениям; кнопка в настройках).
- **Музыка:** «пауза», «играй», «следующий трек», «предыдущий трек» (через активную медиасессию).
- **Фонарик:** «включи фонарик» / «выключи фонарик» (нужно разрешение камеры).
- **Напоминания:** «напомни через 5 минут купить хлеб» — локальный AlarmManager, без облака.
- **Погода:** «какая погода» — Open-Meteo через локальный мост, по грубой геолокации телефона или по IP.
- **Отмена устаревших ответов:** если нажать «стоп» или начать новый запрос, старый поток ответа и речь не проигрываются.

 Runtime-разрешения (микрофон, SMS, звонки) запрашиваются системой при первом запуске. Приложение не рутит устройство и не меняет системные разделы.

## Производительность

После замены модели `qwen3.5:2b` (0.5 ток/с, ответы 2+ минуты) на `qwen3:0.6b` и отказа от тяжёлого агента `orchestrator`:

- типичный ответ: 1.3–2.0 с;
- системный промпт: ~30 токенов вместо ~1400.
- локальные команды (время, дата, батарея, математика, SMS, звонки, приложения, уведомления, музыка, фонарик, напоминания) отвечают мгновенно без модели.

## Удаление

```bash
bash scripts/uninstall-openjarvis.sh
```

На телефоне: Настройки → Приложения → JARVIS → Удалить.

## Безопасность

Всё локально, если не включать необязательный Yandex TTS. Никакой телеметрии и Telegram. Модель не загружается в репозиторий из-за ограничения GitHub на файлы >100 МБ; она скачивается командой `ollama pull qwen3:0.6b`.
